# TeX source of the notes

These files represent the original source for much of the content in `notes/`. They were copied directly from my [doctoral dissertation](https://raymondtana.github.io/my_assets/documents/Raymond%20Tana%20PhD%20Dissertation.pdf).

The `npm run convert` command converts all six chapters into Markdown in `converted_md/` (one folder per chapter, plus `toc.yml` and `report.txt`), ready to move into `notes/`.
